# Design Spec: CMF Connect — экран управления наушниками

Документ предназначен для ИИ-агента, воссоздающего интерфейс на ПК (веб/десктоп). Ниже — полное описание визуальной системы, компонентов, состояний и раскладки.

---

## 1. Общая концепция

- Тёмная тема (dark mode), минималистичный стиль в духе Nothing/CMF.
- Плотная сетка карточек с закруглёнными углами.
- Один яркий акцентный цвет на нейтральном тёмно-сером фоне.
- Микс serif/sans-serif шрифтов как фирменная деталь.

---

## 2. Цветовая палитра

| Назначение | Цвет (HEX) | Комментарий |
|---|---|---|
| Фон приложения | `#121212` | базовый тёмный фон, не чистый чёрный |
| Фон карточек | `#1E1E1E` | немного светлее общего фона |
| Фон второстепенных элементов (неактивные кнопки/иконки) | `#2A2A2A` | круглые кнопки в невыбранном состоянии |
| Акцент (бренд) | `#E8734A` | оранжево-коралловый: цвет наушников, эквалайзер-индикаторы |
| Текст основной | `#FFFFFF` | заголовки, значения |
| Текст вторичный | `#9A9A9A` | подписи-статусы под заголовками карточек |
| Индикатор "онлайн" | `#4CAF50` | зелёная точка статуса подключения |
| Разделитель/трек прогресс-бара (неактивная часть) | `#3A3A3A` | фон полос заряда и сегментированных селекторов |
| Белый активный элемент | `#FFFFFF` | залитые кнопки, ползунки toggle, активные полоски |

---

## 3. Типографика

- Шрифт по умолчанию: системный sans-serif (напр. Inter, SF Pro, Roboto).
- **Исключение**: название модели устройства ("CMF Buds 2") набрано **serif**-шрифтом (напр. Georgia / Times / кастомный serif), тогда как имя владельца в скобках ("Александр") — тем же sans-serif, что и остальной интерфейс. Это осознанный брендинг-приём — сохранить при воссоздании.

| Элемент | Размер | Вес | Цвет |
|---|---|---|---|
| Заголовок экрана ("Устройства") | 28px | Regular/Medium | `#FFFFFF` |
| Имя устройства (serif) | 26px | Regular | `#FFFFFF` |
| Заголовок карточки | 16–17px | Medium | `#FFFFFF` |
| Статус-подпись под заголовком карточки | 13px | Regular | `#9A9A9A` |
| Подписи под прогресс-барами (L 80% / R 65%) | 13px | Regular | `#9A9A9A` |
| Подписи под radio-кнопками (Шумоподавление/Прозрачность/Выкл.) | 13px | Regular | `#FFFFFF` / `#9A9A9A` (в зависимости от состояния) |

## 4. Компоненты

### 4.1 Верхняя панель (Header)
- Заголовок "Устройства" слева, крупный текст.
- Круглый аватар пользователя справа (32–36px, обрезка в круг).
- Ниже — карточка текущего устройства: круглая иконка-эллипс с пиктограммой наушников (фон `#2A2A2A`, иконка белая) + зелёная точка-индикатор статуса поверх иконки (в правом верхнем углу иконки).
- Кнопка "+" справа — круглая, фон `#2A2A2A`, белая иконка плюса, по стилю идентична неактивным radio-кнопкам.

### 4.2 Иллюстрация устройства
- Крупное изображение наушников по центру, на прозрачном/фоновом контейнере без обводки.
- Под изображением — название модели (serif + sans-serif микс, см. п.3).

### 4.3 Индикаторы заряда (Progress bar, тонкий линейный)
- Два коротких горизонтальных бара рядом (для L и R).
- Высота ~3–4px, полностью закруглённые края (`border-radius: 999px`).
- Трек: `#3A3A3A`. Заполнение: `#FFFFFF`, ширина = % заряда.
- Подпись снизу по центру каждого бара: `L 80%`, `R 65%`.

### 4.4 Radio-button group с иконками (напр. Шумоподавление / Прозрачность / Выкл.)
- 3 круглые кнопки диаметром ~64px в ряд, с равным зазором.
- **Активная**: фон `#FFFFFF`, иконка `#121212` (тёмная).
- **Неактивная**: фон `#2A2A2A`, иконка `#FFFFFF`.
- Под каждой кнопкой — подпись; активная подпись белая, неактивные — серые (`#9A9A9A`).
- Компонент — обычная radio-group (одиночный выбор), реализуется как набор `<button>` с `aria-pressed`/`role="radio"`.

### 4.5 Сегментированный селектор-полоска (напр. Низкое/Среднее/Высокое/Адаптивное)
- Горизонтальный ряд тонких капсул-полосок под radio-group.
- Каждая полоска: высота ~4px, ширина ~60–70px, `border-radius: 999px`.
- Неактивная: `#3A3A3A`. Активная (выбранная): `#FFFFFF`, визуально шире/жирнее.
- Подписи под полосками: активная — белый текст, неактивные — серый.
- По сути — второй уровень radio-group, зависимый от первого выбора (напр. степень шумоподавления доступна только при выбранном режиме "Шумоподавление").

### 4.6 Toggle-switch (переключатель вкл/выкл)
- Стандартная капсула iOS-style: ширина ~46px, высота ~26px, `border-radius: 999px`.
- **Выкл. состояние**: фон капсулы `#2A2A2A`/`#3A3A3A`, кружок белый, смещён к **левому** краю.
- **Вкл. состояние**: фон капсулы **остаётся тёмным/нейтральным** (не меняется на акцентный!), кружок белый, смещён к **правому** краю, но при этом кружок увеличен/выделен — это нестандартная реализация: в отличие от классического iOS-переключателя, здесь нет смены цвета фона на акцентный при включении, статус передаётся положением и размером ползунка.
- Рядом с некоторыми тогглами — миниатюрный **эквалайзер-индикатор**: 4–5 вертикальных полосок разной высоты, цвет `#E8734A` (акцент), статичная или анимированная визуализация активности (использован у "Ultra bass" и "Двойное подключение").

### 4.7 Карточки настроек (Settings Card)
- Сетка 2 колонки, равная ширина, gap ~12–16px.
- `border-radius: 20px`, padding ~16px, фон `#1E1E1E`.
- Структура внутри карточки (вертикальный стек):
  1. Заголовок (белый, medium)
  2. Статус-подпись (серый, ниже заголовка)
  3. Элемент управления (toggle / иконка / эквалайзер) в нижней части карточки
- Карточки без обводки, разделены только собственным фоном на фоне приложения.
- Примеры карточек: "Ultra bass" (toggle + эквалайзер), "Эквалайзер" (просто иконка-индикатор, кликабельно ведёт на другой экран), "Управление" (иконка жеста), "Режим малой задержки" (toggle), "Двойное подключение" (toggle + эквалайзер), "Настройки устройства" (иконка шестерёнки).

### 4.8 Карточка "Пространственный звук"
- Полноширинная карточка (не в сетке 2 колонки), с меню "•••" в правом верхнем углу (кнопка дополнительных опций).
- Внутри — 2 круглые radio-кнопки (аналог п.4.4): "Фиксирована" (активна, белый фон) / "Выкл." (неактивна, тёмный фон).

### 4.9 Карточка "Описание"
- Полноширинная, внизу списка.
- Заголовок + значение (название устройства) + иконка информации `(i)` слева снизу.

---

## 5. Layout / Сетка

- Общий контейнер: одна колонка, максимальная ширина адаптируется под ПК (напр. `max-width: 480–560px`, по центру экрана, как мобильный вьюпорт — либо расширить пропорционально для десктоп-версии).
- Вертикальные секции сверху вниз:
  1. Header (заголовок + аватар)
  2. Карточка устройства (иконка + статус + кнопка "+")
  3. Иллюстрация + название модели
  4. Прогресс-бары заряда
  5. Карточка "Шумоподавление" (radio-group + сегментированный селектор)
  6. Карточка "Пространственный звук"
  7. Сетка 2×N карточек настроек
  8. Карточка "Описание"
- Отступы между секциями: ~20–24px.
- Внутренние отступы карточек: ~16px.
- Общий вертикальный скролл страницы.

---

## 6. Прочие стилевые детали

- Все интерактивные круглые элементы (radio-кнопки, кнопка "+") имеют одинаковый радиус скругления — идеальный круг.
- Все прямоугольные карточки — крупный радиус скругления (~16–20px), единый по всему интерфейсу.
- Никаких теней (box-shadow минимален или отсутствует) — плоский (flat) дизайн, разделение элементов через разницу в цвете фона.
- Иконки — line-style (тонкая обводка), белые/серые, без заливки цветом кроме акцентных эквалайзер-полосок.
- Анимации (рекомендация для реализации): плавный переход ползунка toggle (`transition: 0.2s ease`), лёгкая пульсация/анимация эквалайзер-полосок при активном состоянии.

---

## 7. Рекомендуемый стек для реализации

- HTML/CSS (или React + CSS-переменные для темы) — определить палитру как CSS custom properties (`--bg`, `--card-bg`, `--accent`, `--text-primary`, `--text-secondary`).
- Компоненты переиспользуемые: `RadioIconGroup`, `SegmentedControl`, `ToggleSwitch`, `SettingsCard`, `ProgressBar`, `EqualizerIndicator`.
