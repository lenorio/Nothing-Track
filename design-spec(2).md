# Design Spec: CMF Connect — экран "Устройства / Наушники"

> Документ для ИИ-агента, воссоздающего интерфейс на ПК (веб). Все цвета и размеры ниже получены **пиксельным сэмплингом** исходного скриншота (507×2560px, вертикальный мобильный экран), а не визуальной оценкой на глаз — значения проверяемые, не приблизительные "как обычно бывает в dark UI".

---

## 0. Методология / базовые параметры холста

- Референсный скриншот: 507×2560 px (масштабированный дамп экрана телефона).
- Все px-значения ниже даны **в масштабе референсного скриншота**. При переносе на десктоп — пересчитывать пропорционально выбранной ширине контейнера (рекомендация в разделе 8).
- Фон приложения — **чистый чёрный `#000000`**, НЕ тёмно-серый `#121212`, как могло показаться на глаз. Это важно: карточки контрастируют именно с абсолютным чёрным.

---

## 1. Цветовая палитра (измерено пипеткой по пикселям)

| Токен | HEX | Где измерено | Комментарий |
|---|---|---|---|
| `--bg` | `#000000` | фон вне карточек, множественные точки | абсолютно чёрный, не тёмно-серый |
| `--card-bg` | `#1C1C1C` | фон всех карточек (settings card, noise card, spatial card) | единый цвет для ВСЕХ карточек, включая toggle-track (см. ниже) |
| `--surface-alt` | `#1B1B1B`–`#2A2A2A` | фон трека toggle-переключателя / неактивные radio-кнопки | почти идентичен `--card-bg`, трек toggle визуально "растворяется" в карточке — виден только белый кружок |
| `--text-primary` | `#FFFFFF` / `#F1F1F1` | заголовки карточек, значения | |
| `--text-secondary` | `#9A9A9A`–`#A0A0A0` | статус-подписи под заголовками ("Вкл · Уровень 5", "Персонализир.") | ~60% яркости от белого |
| `--accent-status-dot` | `≈#4CAF50` (зелёный) | точка "онлайн" на иконке устройства, bbox x:57–63 y:150–155 | измерено с учётом сглаживания на чёрном фоне |
| `--toggle-thumb` | `#EEEEEE`–`#F1F1F1` | белый кружок toggle | не чистый `#FFFFFF`, чуть притушен |
| `--level-bar-accent` | `#B0393D`–`#AC3C3B` (приглушённый кирпично-красный) | 5-полосный эквалайзер-индикатор рядом с toggle у "Ultra bass" и "Двойное подключение" | **это НЕ оранжевый бренд-акцент!** отдельный, менее насыщенный красный |
| `--brand-accent-earbuds` | градиент `#FF9B74` → `#F9623F` → `#AA2319` | тело наушников (блик → основной тон → тень) | это не плоская заливка, а объёмный градиент/рендер 3D-модели; для плоской иконки-акцента в UI используйте `#F9623F` как основной тон |

**Важное наблюдение:** в этом интерфейсе НЕТ единого "фирменного акцента", используемого повсеместно (как часто рисуют по умолчанию). Оранжевый — только цвет самого устройства (иллюстрация). Красный — только у 5-полосных level-индикаторов. Все элементы управления (toggle, radio, segmented control) — монохромные: белый/серый/чёрный.

## 2. Типографика

- Основной шрифт интерфейса: системный sans-serif (Roboto/SF/Inter-подобный).
- **Название модели устройства** ("CMF Buds 2 (Александр)") набрано **serif**-гарнитурой целиком, включая часть в скобках (похоже на Georgia/PT Serif). Не разбивать на два разных шрифт-стека.

| Элемент | Прибл. размер (px референса) | Пересчёт для десктопа (÷2.1) | Вес | Цвет |
|---|---|---|---|---|
| Заголовок "Устройства" | ~34px | 20-22px | Regular/Medium 500 | `--text-primary` |
| Название модели (serif) | ~32px | 24-26px | Regular 400 | `--text-primary` |
| Заголовок карточки | ~26px | 16px | Medium 500 | `--text-primary` |
| Статус-подпись под заголовком | ~22px | 13px | Regular 400 | `--text-secondary` |
| Подписи под progress-барами (L 80%) | ~20px | 13px | Regular 400 | `--text-secondary` |
| Подписи под radio-иконками | ~22px | 13px | Regular 400 | активная: `--text-primary`, неактивная: `--text-secondary` |

## 3. Точная сетка карточек (2 колонки) — измеренные пропорции

Замер по горизонтальному скану строки внутри карточки (y=2060 в референсе):

```
|←17px→|←────231px────→|←5px→|←────231px────→|←23px→|
 margin      card-L       gap       card-R      margin
```

Итого ширина холста 507px = 17 + 231 + 5 + 231 + 23.

**В относительных единицах (рекомендуется для CSS):**
- Внешние отступы контейнера: небольшая асимметрия в оригинале (17px/23px) — на практике сделайте одинаковыми `16-20px` слева-справа.
- Карточки: `width: calc(50% - gap/2)`, `gap: 10-12px`.
- `grid-template-columns: 1fr 1fr;`

**Радиус скругления карточек:** измерен по кривизне угла — переход от скруглённой к прямой границе происходит на промежутке ~17px по X и ~10px по Y от угла карточки. Соответствует `border-radius ≈ 18-20px` в масштабе референса → **на десктопе используйте `border-radius: 20px`** (единый для ВСЕХ карточек и внешнего блока "Шумоподавление"/"Пространственный звук").

**Высота карточки в сетке 2×N:** карточки **не имеют фиксированной равной высоты** в пределах ряда — каждая подстраивается под свой контент (`align-items: start` в grid, а не `stretch`). Двухстрочные заголовки (напр. "Режим малой задержки") делают карточку выше, чем однострочные ("Ultra bass").

## 4. Инвентарь компонентов (полный, с точными состояниями)

### 4.1 Header
- Слева: текст "Устройства", крупный.
- Справа: круглый аватар пользователя, ~40px диаметр (референс), обрезан в круг, `object-fit: cover`.
- Отступ header от края экрана: те же ~17px, что и у карточек (единая сетка отступов на всю страницу).

### 4.2 Карточка текущего устройства (иконка-переключатель устройств)
- Круглая иконка (эллипс) слева, фон `--card-bg`, внутри — белая пиктограмма наушников (line-style, две капсулы).
- Диаметр иконки ~55px (референс).
- **Зелёная точка-индикатор** статуса подключения — маленький кружок ~10px, в правом верхнем углу иконки, цвет `--accent-status-dot`, обводка в цвет фона (`--bg`) толщиной ~2px для эффекта "вырезанного" кружка.
- Справа на этом же уровне — кнопка "+" в отдельном круге того же диаметра (~55px), фон `--card-bg`, белая иконка плюса по центру.

### 4.3 Иллюстрация наушников
- Крупное центрированное изображение, занимает почти всю ширину контейнера, высота ~500px в референсе.
- Для веб-реализации: PNG/WebP-рендер с прозрачным фоном (реалистичная иллюстрация с градиентом и бликами, см. `--brand-accent-earbuds`), либо SVG с линейным градиентом `#FF9B74 → #F9623F → #AA2319`.
- Под иллюстрацией — название модели (см. типографику).

### 4.4 Progress bar заряда (L/R)
- Два коротких горизонтальных бара рядом, каждый ~70px шириной, ~4px высотой (референс), `border-radius: 999px`.
- Трек: серый чуть светлее фона (`≈#3A3A3A`); заполнение — `--text-primary` белый, ширина = % заряда.
- Подпись под каждым баром по центру, `--text-secondary`, формат `"L 80%"` / `"R 65%"`.
- Зазор между двумя барами ≈ 20px (референс).

### 4.5 Карточка "Шумоподавление" — двухуровневый селектор

**Уровень 1 — Radio-icon-group (режим):**
- 3 круглые кнопки-иконки в ряд, диаметр ~85px (референс) — самый крупный круглый элемент управления на экране.
- **Активная кнопка**: фон `#FFFFFF`, иконка внутри тёмная (`#1C1C1C`).
- **Неактивные кнопки**: фон `--surface-alt` (≈`#2A2A2A`), иконка белая.
- Подпись под каждой кнопкой: активная — белый текст, неактивные — `--text-secondary`.
- Иконки (line-style, ~24px): "Шумоподавление" — ухо/наушник с волной; "Прозрачность" — пунктирный круг из точек; "Выкл." — перечёркнутый динамик.

**Уровень 2 — Segmented level selector (зависимый, активен только при режиме "Шумоподавление"):**
- 4 горизонтальные капсулы-полоски в ряд: "Низкое / Среднее / Высокое / Адаптивное".
- Каждая полоска: ширина ~85px, высота ~5px, `border-radius: 999px`.
- Неактивная: `--surface-alt`. Активная (здесь "Высокое"): `#FFFFFF`.
- Подпись под каждой полоской: активная — белый текст, неактивные — `--text-secondary`.
- Заголовок карточки сверху: "Шумоподавление" + статус `"Вкл · Высокое"` (отражает выбор обоих уровней).

### 4.6 Карточка "Пространственный звук"
- Полноширинная карточка (не часть 2-колоночной сетки).
- В правом верхнем углу — кнопка доп. меню "•••", без фона, белые точки.
- Внутри — Radio-icon-group из **2** кнопок (тот же стиль, диаметр ~85px): "Фиксирована" (активна, белый фон, иконка солнце/диафрагма) / "Выкл." (неактивна, тёмный фон, иконка сфера/шар).
- **Нет** второго уровня (сегментированного селектора), в отличие от карточки шумоподавления.

### 4.7 Toggle-switch — ДВА РАЗНЫХ ВАРИАНТА (важно не перепутать!)

**Вариант А — простой on/off (используется в "Режим малой задержки", статус "Вкл."):**
- Капсула-трек: ~55×30px (референс), `border-radius: 999px`, цвет трека сливается с фоном карточки.
- Белый кружок-thumb (~28px диаметр) смещён к **правому** краю трека при "Вкл.". При "Выкл." — смещается влево (стандартное поведение, не зафиксировано явно в референсе).

**Вариант B — toggle + уровень (используется в "Ultra bass" и первой карточке "Двойное подключение"):**
- Тот же трек, но белый кружок **всегда прижат к левому краю**, независимо от текстового статуса ("Ultra bass" подписан как "Вкл · Уровень 5", "Двойное подключение" — "Выкл.", но кружок в обоих случаях слева) — **позиция кружка здесь не индикатор вкл/выкл, полагаться на неё нельзя.**
- Справа от переключателя — отдельный **5-полосный индикатор уровня**, цвет `--level-bar-accent`, 5 вертикальных штрихов разной длины, статичные.
- Рекомендация: реализовать как составной компонент `ToggleWithLevel`, где toggle отвечает за вкл/выкл функции, а 5 полосок — отдельный индикатор уровня (0-5).

### 4.8 Статичные карточки-ссылки (без toggle)
- **"Эквалайзер"** ("DIRAC Opteo") — иконка мини-эквалайзера (вертикальные полоски разной высоты, line-style, белая).
- **"Управление"** ("Персонализир.") — иконка жеста (рука с волновыми линиями).
- **"Настройки устройства"** — иконка шестерёнки.
- **"Двойное подключение"** (второй экземпляр, "Выкл.") — иконка "слоёв"/ромбов (multipoint) вместо toggle.
- **"Описание"** — полноширинная карточка: заголовок + значение (название устройства текстом) + иконка `(i)` info внизу слева.

> Наблюдение: карточки "Управление", "Режим малой задержки", "Двойное подключение"/"Настройки устройства" **дублируются** в нижней части списка с другим набором иконок — похоже на артефакт склейки двух состояний экрана в одном скриншоте. При реализации возьмите только один непротиворечивый набор (первое появление каждой карточки).

## 6. Компонент: Toggle Switch (код-пример)

Вариант A — простой on/off:

```html
<button class="toggle" role="switch" aria-checked="true">
  <span class="toggle__thumb"></span>
</button>
```

```css
.toggle {
  width: 46px;
  height: 26px;
  border-radius: var(--radius-pill);
  background: var(--toggle-track);
  border: 1px solid var(--border-subtle);
  position: relative;
  cursor: pointer;
  padding: 0;
}
.toggle__thumb {
  position: absolute;
  top: 2px;
  left: 2px;
  width: 22px;
  height: 22px;
  border-radius: 50%;
  background: var(--toggle-thumb);
  transition: transform 0.2s ease;
}
.toggle[aria-checked="true"] .toggle__thumb {
  transform: translateX(20px);
}
```

Вариант B (с level-барами) — тот же `.toggle` (кружок остаётся слева, `aria-checked` управляет только затемнением/прозрачностью, не позицией), плюс соседний элемент:

```html
<div class="toggle-with-level">
  <button class="toggle" role="switch" aria-checked="true"><span class="toggle__thumb"></span></button>
  <div class="level-bars" aria-label="Уровень 5 из 5">
    <span style="height:6px"></span>
    <span style="height:9px"></span>
    <span style="height:12px"></span>
    <span style="height:15px"></span>
    <span style="height:18px"></span>
  </div>
</div>
```

```css
.toggle-with-level { display: flex; align-items: center; gap: 12px; }
.level-bars { display: flex; align-items: flex-end; gap: 3px; }
.level-bars span { width: 3px; background: var(--accent-level-bar); border-radius: 2px; }
```

## 11. Известные несоответствия в исходном скриншоте (не переносить как баг)

1. Карточки "Управление", "Режим малой задержки", "Двойное подключение"/"Настройки устройства" **дублируются** в нижней части списка с другим набором иконок — вероятно, это склейка двух состояний экрана. Использовать только один набор.
2. Позиция белого кружка в toggle "Ultra bass"/"Двойное подключение" **не коррелирует** явно с текстовым статусом "Вкл"/"Выкл" — см. п. 4.7, реализовать как раздельные состояния (toggle state + level value).
3. Асимметрия внешних полей (17px слева / 23px справа при измерении) — на десктопе сделать симметричными.
